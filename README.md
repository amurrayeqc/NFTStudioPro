# NFTStudioPro

NFTStudioPro optimizes network throughput and enables real-time processing via auto-scaling, integrating seamlessly with blockchain APIs and decentralized platforms.

NFTStudioPro is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTStudioPro.git`
2. `cd NFTStudioPro`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NFTStudioPro, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
